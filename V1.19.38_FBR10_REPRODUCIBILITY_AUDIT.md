# FlyBrain V1.19.38 — FBR-10 reproducibility repair

V1.19.37 CI exposed a real reproducibility defect.

The frozen production binary is:
0044ab166af3439f2b86d4e6c5897481a1c3f28a58b6afb2c4f761489b276bbf

The current heuristic rebuild produced:
4d643835b7e924ace93fb4b36500a1195d4f8129318da79a5f4df84bb6dc8cda

The discrepancy was not merely a hash/contract problem: the rebuilt population
ranges differed (for example visual 1586 vs frozen 977), proving that the
selection heuristic had diverged from the frozen FBR-10.

V1.19.38 therefore freezes the exact 16,669 retained MaleCNS bodyIds in
tools/fbr10_frozen_body_ids.txt. The builder now fails closed if the pinned
source does not contain that exact set and fails closed if the regenerated
FBC103 SHA-256 is not 0044ab166af3439f2b86d4e6c5897481a1c3f28a58b6afb2c4f761489b276bbf.

No neural/locomotor/yaw code was changed.
No connectome edge is invented.
The frozen FBR-10 remains the canonical production substrate.
