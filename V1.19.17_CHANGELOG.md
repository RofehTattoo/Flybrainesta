# FlyBrain V1.19.19 — focal corrections

## Changes
- Routed runtime ORN firing-rate inputs through `OlfactoryInputEncoder`, the same encoder covered by the Kotlin unit tests. Bilateral side assignment and center-channel handling are retained.
- Removed the software-derived feeding pause from the leg actuator input. The actuator now receives only measured retained walk-OFF neural activity; feeding readouts remain diagnostic and do not directly inhibit locomotion.
- Hardened the visual FBR-10 rebuild validation: a missing report or bootstrap report without canonical visual fields is a failure, not a successful `SKIP`.
- Synchronized active app/build metadata and current-contract tests to version 1.19.19 / versionCode 158.
- Added a static regression contract for runtime encoder use and the neural-only walk-OFF actuator path.

## Validation limitations
This source ZIP does not contain the canonical CI-generated connectome/dynamics assets or a built APK. The full MaleCNS reconstruction and Android build must run in GitHub Actions before calling the release fully validated. No synthetic neurons, edges, or behavior-to-motor shortcuts were added.
