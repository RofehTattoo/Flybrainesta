# FlyBrain V1.13 — Technical Audit

## Purpose

V1.13 is a diagnostic and causal-integrity correction of V1.12 FIXED4. It does not add synthetic neurons or synthetic connectome edges. The runtime continues to load the deterministic 16,669-neuron MaleCNS reduction in FBC103.

## Corrections made

1. **Neural observability**
   - The lower panel now reports real runtime spike counts, spikes/s, loaded edge count, displayed neuron count and displayed real edges.
   - Representative neurons explicitly include the retained FG/BB/BRK halt annotations when present.
   - Displayed connections are real retained edges only.
   - Inactive real edges are made visibly readable; active edges increase width/brightness with `visualActivity`.
   - The panel no longer implies that all 16,669 neurons are literally rendered one-by-one.

2. **RESET is a real experimental reset**
   - Clears LIF state, refractory state, synaptic traces and visual activity.
   - Clears all environmental stimuli.
   - Resets body position and physical-motion diagnostics.
   - Resets spike counters and diagnostic displays.

3. **No artificial background neural activity**
   - Removed the stochastic central current used by V1.12.
   - With no sensory input, any firing must come from retained network dynamics rather than an unlabelled random current.

4. **Physical locomotion is separated from neural motor activity**
   - LOCOMOTION is no longer declared merely because arbitrary motor/neck/jump neurons fired.
   - The body state is read from actual displacement of `flyX/flyY` over time.
   - Leg motor activity remains a neural diagnostic and contributes to the existing body mechanics, but it is not itself the definition of physical locomotion.
   - Pause/stop detection uses a short physical-motion memory so that a movement episode can correctly transition into an immobile bout.

5. **Runtime fail-closed checks**
   - Empty required sensory, descending, ascending or motor populations are rejected.
   - A connectome with zero edges is rejected.
   - A diagnostic map with no representable real edge is rejected unless real edge endpoints can be added from the loaded graph.

6. **Build identity**
   - Android version code: 113
   - Android version name: 1.13
   - Connectome format: FBC103
   - Reduced neurons: exactly 16,669
   - Edge record size: 12 bytes
   - Node record size: 26 bytes

## Scientific constraint

V1.13 deliberately does **not** add a timer, random walk, forced rest, stimulus-to-motor shortcut, synthetic halt current, or synthetic connectome edge. If a stimulus fails to propagate through the retained network, the diagnostics are intended to expose where the chain stops rather than conceal the failure with a behavioural fallback.

## Validation

The GitHub Actions workflow performs:

- Python syntax checks.
- Independent FBC103 binary validation.
- Report consistency checks.
- Kotlin structural checks.
- APK compilation.
- `zipalign` verification.
- `apksigner verify --verbose` verification.
- APK manifest/version/resource checks.

A successful static package is **not** claimed to be a successful Android build until the GitHub Actions run itself reaches the final APK validation step.
