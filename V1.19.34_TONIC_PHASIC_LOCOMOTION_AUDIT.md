# FlyBrain V1.19.34 — Tonic/Phasic Locomotion Correction

## Objective

Correct the V1.19.33 behavioural failure in which the fly could behave like a wind-up toy: once locomotion started, tonic/background VNC motor activity could keep the six-leg mechanical oscillator running continuously.

## Root cause

The V1.19.30–V1.19.33 motor decoder deliberately preserved tonic motor-neuron firing by mixing:

- tonic activity: 42%
- phasic/burst activity: 58%

That mixture was then sent directly to `LeggedSensorimotorActuator`. The actuator interprets non-zero activation as permission to advance each leg phase. Consequently, a persistent physiological motor baseline became a persistent locomotor clock.

This was not a food/light/danger shortcut; it was a causal-layer error in the neural-to-mechanics decoder.

## V1.19.34 correction

The motor decoder now keeps tonic firing as diagnostic/physiological information but uses only the measured phasic/burst component as locomotor phase drive:

`target = burst.coerceIn(0f, 1f)`

The mechanical actuator still receives only the six measured VNC leg-group streams plus the independently measured FG/BB walk-OFF and BRK brake states. It contains no food, danger, wall, approach, orientation or software behaviour command.

The actuator remains stateful: leg phase advances only while its neural locomotor input is above the existing motor threshold. It does not run an independent animation clock.

## Why this is preferable to simply reducing speed

Reducing `MAX_FORWARD_SPEED`, acceleration, or phase frequency would leave the causal error intact: tonic neural activity would still create locomotion. V1.19.34 instead removes the tonic-to-gait conversion at the neural/mechanical boundary.

The intended consequence is:

1. background/tonic VNC firing alone → no indefinite walking;
2. phasic motor recruitment from the retained neural circuit → stepping;
3. loss of phasic motor recruitment → gait phase stops advancing and mechanical velocity damps;
4. walk-OFF/BRK neural populations → independent mechanical inhibition;
5. olfactory/food behaviour remains upstream of the retained neural circuit and is not wired directly to the body actuator.

## Expected behavioural change in the APK

With no food or other stimulus, the fly should no longer enter indefinite locomotion merely because the retained VNC motor populations have tonic/background firing.

When the olfactory→descending→VNC pathway recruits a phasic locomotor pattern, the fly should produce genuine stepping. As that phasic drive disappears, the gait should stop rather than continue indefinitely.

This version therefore targets the observed “carrito con cuerda” failure at its causal source rather than masking it with a lower speed constant.
