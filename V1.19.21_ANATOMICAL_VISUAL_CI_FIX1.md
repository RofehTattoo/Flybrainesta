This is not evidence that AMMC anatomy is wrong. It means no retained

The unit test still verifies that a Johnston-organ annotation is classified as
`AMMC`; the generated-map validation no longer requires a region to be
non-empty when that population is absent from the retained connectome.

No neural graph, neuron selection, edge, weight, sensory route, or runtime
behavior was changed.
