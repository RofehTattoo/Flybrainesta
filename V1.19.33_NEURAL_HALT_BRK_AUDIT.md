# FlyBrain V1.19.33 — NEURAL HALT / BRK

## Purpose

V1.19.33 is a focused locomotor-control revision based on V1.19.32_REGRESSION_RECOVERY.
It does **not** change FBR-10-OLF2-MOTORROUTE neuron selection, ORN selection, retained
edges, sensory encoders, or wall-escape behavior.

The change is specifically to separate the two retained neural halt mechanisms:

- FG / Foxglove and BB / Bluebell: walk-OFF populations.
- BRK / Brake (AN19A018): distinct VNC brake population.

## Runtime change

`MainActivity` now measures BRK spikes over the complete 20 ms neural frame, converts
the measured BRK population rate into `brakeActivationState`, and passes that state to
the legged actuator separately from `walkOffActivationState`.

Runtime metadata validation now fails fast if no retained BRK population is present.

The actuator treats BRK as resistance:

1. BRK suppresses stepping frequency progressively.
2. BRK reduces stance propulsion progressively.
3. BRK adds velocity-proportional mechanical resistance.
4. BRK never writes position, heading, gait phase, or a synthetic turn.

Walk-OFF remains a separate measured inhibitory gate. No food, wall, light, danger,
`approachAction`, `orientAction`, or other behavioral selector is consulted by the
actuator.

## Connectome integrity

The canonical reduction remains:

- 16,669 retained neurons.
- FBR-10-OLF2-MOTORROUTE.
- MaleCNS v1.0 source hashes unchanged.
- No synthetic graph edges.
- No changes to FBC103 selection logic.

The CI workflow rebuilds the canonical FBC103 from the pinned MaleCNS source before
validation; the checked-in bootstrap binary/report is intentionally not treated as the
canonical CI artifact.
