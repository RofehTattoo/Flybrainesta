# FlyBrain V1.17.0 — FBR-10-OLF1

## Purpose
V1.17.0 addresses the empirically observed failure where the retained olfactory input produced strong ORN activity but failed to recruit locomotion before close-range contact. The correction is structural: the 16,669-neuron reduction is regenerated from official MaleCNS v1.0 with explicit olfactory preservation.

## Structural rules
- FBC103 format remains unchanged.
- The frozen FBC103 baseline is preserved as the source bootstrap artifact; CI generates the V1.17.0 FBR-10-OLF1 graph in-place immediately before application build. The generated release hash is recorded in the new report.
- 264 ORNs are retained: 10% of the 2,639 ORNs rounded to the nearest whole neuron.
- All 54 published ORN `(type, entryNerve)` combinations must be represented; these correspond to 53 unique non-null `type` labels because `ORN_VA7l` occurs under both AN and MxLbN.
- Real ORNs are channel=olfactory; historical `ol_sensory` visual cells are not olfactory.
- Explicit measured `route_olfactory_forward` and `route_olfactory_motor` scores protect published ORN-driven sensorimotor intermediates.
- No synthetic neuron or edge is created.

## Runtime invariants
COMIDA still enters only the retained ORN population and propagates through the connectome/dynamics to DN, VNC and motor neurons. `driveBody()` remains downstream of measured VNC motor activity; no direct COMIDA-to-speed/turn/approach path is introduced.

## Validation requirement
CI must rebuild `malecns_reduced.bin`, generate the ORN input map and VNC semantics, validate FBR-10-OLF1, build FBD104, and then assemble the APK.
