# V1.16.2 — Neural time integration audit

## Scope
This release changes only the runtime numerical integration of the membrane leak in `MainActivity.kt`.

## Correction
The prior membrane update used an Euler leak term with `tau_m = 20 ms` and a fixed neural step of `dt = 20 ms`. That gave an Euler retention factor of `1 - dt/tau = 0`, erasing subthreshold membrane state at every neural tick.

V1.16.2 keeps the same 20 ms time constant but uses the exact exponential retention factor:

`exp(-dt / tau_m)`

At `dt = tau_m = 20 ms`, the retention is `exp(-1) = 0.367879...`.

The synaptic trace constant (5 ms), FBC103 topology, FBD104 artifact, sensory mapping, motor semantics, and body mechanics are unchanged.
