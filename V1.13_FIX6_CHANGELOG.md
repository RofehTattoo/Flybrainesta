# FlyBrain V1.13 FIX6

## Build/CI fix

FIX6 corrects the failure in **Validar estructura Kotlin V1.13**.

### Root cause
The structural validator incorrectly contained a negative assertion requiring the literal `FBC103` to be absent from `MainActivity.kt`. V1.13 legitimately displays the binary format and reports connectome errors using `FBC103`, while the actual binary parser correctly obtains the magic from `GeneratedConnectomeMeta.FORMAT_MAGIC`.

The validator now checks the correct architectural invariant:

- `GeneratedConnectomeMeta.FORMAT_MAGIC` is referenced by the parser.
- `magicText != GeneratedConnectomeMeta.FORMAT_MAGIC` is used for validation.
- There is no hard-coded `magicText != "FBC103"` parser comparison in `MainActivity.kt`.

No neural/connectome behavior was changed in FIX6.

## FBR-10 reducer added

A new independent reducer, `tools/build_connectome_fbr10.py`, implements the agreed Philosophy A reduction. It is deliberately separate from the historical selector so previous builds remain reproducible.

The FBR-10 stage fixes several conceptual issues in the historical reducer:

- exactly 16,669 neurons is the hard constraint;
- neuron types are a soft diversity objective, not a forced 10%-of-types quota;
- descending and VNC motor populations are preserved as hard anchors;
- route/connectivity/architecture scores are explicit and weighted;
- the structural output is the strict induced subgraph of MaleCNS v1.0;
- no synthetic edges are created and unknown neurotransmitter signs are not allowed to delete structural edges;
- FBR-10 is validated independently before Android runtime integration.

The structural FBR-10 binary must **not** be wired into the APK until `tools/validate_fbr10.py` reports PASS and the full structural audit has been reviewed.
