# FlyBrain V1.19.22 — visual density + manual startup gate

V1.19.22 is a small presentation/control correction on top of V1.19.21.

## Changes
- Neural map node rendering is reduced in size, especially for dense non-representative active populations.
- Active extra neurons are rendered as micro-nodes without large halos to prevent the central brain from collapsing into a solid cloud on phone displays.
- Representative nodes and connectome edge strokes are reduced modestly for improved spatial legibility.
- The startup observatory no longer auto-dismisses. The real connectome/dynamics can continue loading in the background while the user reads the legend.
- An actual Android `INICIAR SIMULACIÓN` button appears in the startup screen and is enabled only after the connectome and dynamics report ready.
- The simulation clock and neural updates remain paused until the user presses Start.

No neurons, synapses, weights, sensory encoders, or locomotion dynamics were changed by this release.
