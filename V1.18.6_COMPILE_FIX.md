# v1.18.6 compile fix

## CI failure diagnosed
The CI log reached `:app:compileDebugKotlin` and failed on two Kotlin issues in
`MainActivity.kt`:

1. `const val` declarations were inside a class scope where Kotlin only permits
   compile-time constants at top level, in named objects, or in companion objects.
   These runtime configuration values are now ordinary `private val` properties.
2. `FEEDING_FUNCTION_INGESTION_CROP_ENTRY` is generated in
   `GeneratedConnectomeMeta`; references from `MainActivity` now use the fully
   qualified `GeneratedConnectomeMeta.FEEDING_FUNCTION_INGESTION_CROP_ENTRY`.

The related static regression tests were updated to assert the valid Kotlin
scope and qualified constant reference.

No connectome data, neuron selection, synapses, LIF dynamics, sensory encoding,
food-contact behavior, or causal-turn logic was changed.
