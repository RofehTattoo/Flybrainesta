# V1.19.29 CI FIX7 — manifest release-label synchronization

## Root cause

The canonical FBR-10 build and the V1.19.29 locomotion tests reached the structural
validation stage successfully. CI stopped in `tools/test_v120_locomotion_validation.py`
because the test still asserted:

`android:label="FlyBrain V1.19.28"`

while the release identity is V1.19.29.

The AndroidManifest itself was also still carrying the previous release label.

## Fix

Both the validator contract and `AndroidManifest.xml` now use:

`android:label="FlyBrain V1.19.29"`

No FBR-10 topology, neural routing, six-leg mechanics, wall logic, or locomotion
behavior was changed by this CI-only correction.
