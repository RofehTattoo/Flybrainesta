# FlyBrain V1.18.7 — six-leg motor-actuator audit

## Problem identified in V1.18.6
The previous body decoder treated all retained VNC leg motor neurons as one population mean and converted that scalar directly into continuous point-mass translation. The rendered fly used a fixed six-leg pose, so the neural output could not express stance/swing timing, tripod coordination, or a true motor-driven stop. Wings also contributed to ground translation, and arena boundaries reflected heading like a billiard ball.

## V1.18.7 correction
The connectome, FBC103 structure, LIF dynamics, olfactory route, tarsal gustatory interface, and causal-yaw equation are unchanged. Runtime VNC semantics already contain the official MaleCNS `subclass` field (`fl`, `ml`, `hl`) and `somaSide`; the runtime now preserves that information as six actuator groups: LF, LM, LH, RF, RM, RH.

The body decoder now:

- filters each of the six measured leg motor groups independently;
- advances a gait phase only while measured leg motor output is present;
- applies the established modified-tripod phase relation as a biomechanical actuator constraint, not a sensory or action command;
- computes ground support from the currently active stance legs rather than a single population mean;
- removes wing activity from ground translation;
- allows measured FG/BB walk-OFF output to reduce locomotor drive in the same neural frame;
- uses inertial yaw and tangential wall collision rather than an artificial heading reflection;
- animates coxa/knee/tibia/tarsus from the same six measured motor groups.

The gait phase is not a free-running behavioral oscillator: it freezes when the retained leg motor output falls below the locomotor threshold. Thus a neural loss of leg drive produces a mechanical stop instead of a perpetual glide.

## Feeding relation
Tarsal contact remains a sensor input only. Feeding is still acknowledged only from the retained feeding motor neurons (MN9/MN4a/MN6/MN8/MN11D/MN11V/CEM). Walk-OFF, rather than the non-feeding BRK brake population, is the feeding-relevant halting evidence. No `food -> speed`, `food -> heading`, `food -> proboscis`, or synthetic connectome edge was added.

## Release integrity
FBR-10/FBC103 is not regenerated or structurally edited by this release change. The CI workflow continues to build the canonical current reduction from the pinned MaleCNS source; V1.18.7 changes runtime decoding only.
