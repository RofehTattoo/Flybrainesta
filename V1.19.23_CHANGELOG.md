# FlyBrain V1.19.23 — CI compile fix for manual START gate

V1.19.23 is a focused correction of V1.19.22.

## Root cause of the GitHub failure
GitHub Actions completed the connectome, dynamics and validation stages and failed only during `:app:compileDebugKotlin`. `StartupView.onDraw()` referenced `startButton`, but V1.19.22 declared that button as a local variable inside `onCreate()`. Kotlin consequently reported four `Unresolved reference 'startButton'` errors.

## Correction
- `startButton` is now an Activity-level `lateinit var`.
- The local shadow declaration was removed.
- The existing manual-start behavior is unchanged: loading may occur in the background, but the simulation does not start until the user presses START.
- The UI density/anatomical rendering changes are untouched.
- No connectome selection, synapses, sensory encoders, locomotion mechanics or anatomy mapping were modified.
