# FlyBrain V1.19.27 — Neural yaw wall deadlock fix

## Root cause
The locomotor actuator multiplied neural yaw by `translationYawGate`, which was derived from `forwardVelocity`. Physical wall contact can reduce forward velocity to approximately zero. On the next neural step this forced the yaw target to zero even when bilateral leg-motor activity remained asymmetric, creating a locomotor deadlock at the wall.

## Correction
Removed only the forward-translation prerequisite from the neural yaw path. Neural yaw remains generated from measured bilateral leg propulsion imbalance (`turnBalance * turnDrive`) and the existing walk-off suppression gate.

## Preserved constraints
- No wall -> turn command.
- No synthetic yaw written by collision code.
- No gait phase manipulation from collision code.
- No direct stimulus -> motor shortcut.
- No new neurons or synapses.
- FBR-10 topology unchanged.

## Expected causal path
mechanosensory contact -> retained neural circuit -> bilateral motor asymmetry -> neural yaw -> body reorientation.
