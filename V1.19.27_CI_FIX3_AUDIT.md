# FlyBrain V1.19.27 — CI FIX3 audit

## Failure observed
GitHub Actions reached canonical FBR-10 generation successfully:
- 16,669 retained neurons
- 2,072,633 retained edges
- MaleCNS v1.0
- FBR-10-OLF2-MOTORROUTE
- canonical binary SHA256 `4d643835b7e924ace93fb4b36500a1195d4f8129318da79a5f4df84bb6dc8cda`

The next validation failed in `tools/test_v11916_visual_fbr10_rebuild.py`:
`AssertionError: assert 'versionCode = 167' in GRADLE`

## Root cause
The release was internally inconsistent:
- `app/build.gradle.kts` declared `versionName = "1.19.27"` and `versionCode = 168`.
- generated/source metadata and multiple regression contracts still declared `APP_VERSION_CODE = 167` / expected `versionCode = 167`.
- `tools/build_connectome.py` also regenerated metadata with code 167.

Therefore CI generated a coherent canonical connectome but the release validation contract rejected the Android version metadata.

## Fix
V1.19.27 CI FIX3 makes the existing V1.19.27 release internally consistent at:
- versionName: `1.19.27`
- versionCode: `168`

Updated:
- app Gradle metadata
- GeneratedConnectomeMeta
- connectome generator metadata
- regression tests that assert the V1.19.27 application version code

No FBR-10 topology, neuron selection, synapse selection, sensory encoding, obstacle logic, or locomotion behavior was changed.

## Important
This is a CI/release-contract correction. It does not claim to solve the physical wall deadlock. The APK produced after this fix is the required next artifact for behavioral testing.
