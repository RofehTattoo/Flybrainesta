# FlyBrain V1.13 FIX5 — validation hotfix

## Root cause of the CI failure
The independent FBC103 validator still contained a V1.12 release assertion:
`assert report["flybrain_version"] == "1.12"`.

The V1.13 generator correctly emits `flybrain_version: "1.13"`, so the validator rejected a valid V1.13 connectome before inspecting its binary structure.

## Fix
- Validator release constant is now `RELEASE_VERSION = "1.13"`.
- Report validation uses that constant.
- Validator checks `app/build.gradle.kts` has the same `versionName`.
- Workflow checks the validator itself is configured for V1.13 before executing it.
- No connectome data, neuron selection, edge selection, LIF dynamics, or behavioural logic was changed by this hotfix.
