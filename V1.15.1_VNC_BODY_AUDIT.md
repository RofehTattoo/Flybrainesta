# FlyBrain V1.15.1 — VNC → Body Mechanics Surgical Correction

## Scope

V1.15.1 keeps the frozen FBR-10 structural artifact **bit-for-bit unchanged** and keeps the derived FBD104 signed dynamics convention unchanged. This release only corrects the VNC motor-output interpretation and the body/environment interface so that the upcoming behavioral measurements are not dominated by implementation artifacts.

## Corrections

### 1. Fixed denominator normalization of VNC motor roles

Motor-role activity is now normalized by the **fixed total number of retained VNC motor neurons in each role**, not by the number of neurons that happened to fire in the current frame.

For the frozen FBR-10 VNC motor block (708 neurons), the audited role census is:

- LEG: 213
- WING: 26
- JUMP: 2
- OTHER: 467
- HALTERE/NECK/ABDOMEN: 0 in this frozen runtime block

Leg side census:

- left: 108
- right: 105
- unknown: 0

Therefore a single firing LEG MN is no longer interpreted as `LEG = 1.0`.

### 2. Left/right steering uses fixed side denominators

Left and right leg activity are normalized independently by the retained anatomical side counts (108 left, 105 right). Side-unknown leg neurons, if present in a future frozen layer, contribute to total leg activity but do not create an invented steering side.

### 3. Removed stimulus identity from `driveBody()` turning normalization

`COMIDA`, `LUZ`, and `PELIGRO` no longer select a separate body-turn normalization branch. The baseline turn normalization now depends only on measured body quiescence and motor/body state. There is no direct stimulus-to-turn term in body mechanics.

### 4. Food intake no longer requires locomotion

The intake event now requires only:

- physical proximity to food, and
- measured gustatory population activity.

This allows the virtual fly to stop at food and ingest rather than requiring simultaneous leg locomotion.

### 5. Locomotion/rest telemetry is body-derived

`stableLocomotion` and the recent movement memory now follow measured physical movement rather than treating neural leg firing itself as evidence that the body moved.

## Read-only audit telemetry

The neural diagnostic card now exposes:

- LEG active / total
- left LEG active / total
- right LEG active / total
- WING active / total
- JUMP active / total
- OTHER active / total
- ESC-N

The telemetry is read-only and never feeds back into neural dynamics or body mechanics.

## Explicit non-changes

- `malecns_reduced.bin` is not regenerated or modified.
- FBR-10 neuron census remains 16,669.
- FBR-10 structural edge census remains 2,064,951.
- FBR-10 frozen SHA-256 remains `bfadc30fd113c25f9711cce6ef8f6b80e9c139fe6d229965a4adabb94d8b4e60`.
- FBD104 is still derived from the pinned official MaleCNS neurotransmitter Feather and does not invent neurons or edges.
- Adaptive synaptic-gain calibration remains removed.
- Diagnostic values remain read-only.

## Validation sequence

After build, repeat only the minimum targeted checks:

1. Baseline: no stimulus, confirm role counters remain interpretable.
2. COMIDA: fixed food position / contact test; verify food can trigger gustatory activity and that locomotion is not required for an intake event.
3. PELIGRO: fixed stimulus; compare LEG L/R recruitment, physical speed, heading, path length, and ESC-N.
4. Only then resume the formal T5 protocol.
