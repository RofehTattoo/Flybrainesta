# FlyBrain v1.18.4 — Audio, UI y locomoción

## Cambios

- **Audio:** sustituido `app/src/main/res/raw/fly_buzz.wav` por un loop WAV mono de 48 kHz/16-bit, con armónicos de batido alado, modulación suave y ataque/cola de bucle suavizados. `MainActivity` ya carga ese recurso mediante `R.raw.fly_buzz`; no hace falta cambiar la ruta.
- **Panel inferior:** el fondo oscuro ahora se dibuja desde `x=0` hasta `x=width`, sin márgenes laterales ni esquinas redondeadas que dejen ver el fondo claro. Se aumenta moderadamente el tamaño de varias etiquetas y cifras. El contenido conserva un margen interno para no quedar pegado al borde.
- **Locomoción:** se añade una fluctuación angular de media cero, limitada y temporalmente correlacionada, solo cuando hay actividad locomotora. No depende de la posición, de las paredes, del alimento ni de la identidad del estímulo; por tanto, no codifica un giro preferente a derecha o izquierda. La propulsión y el avance siguen dependiendo de la actividad motora VNC.
- **Versión:** `versionCode 137`, `versionName 1.18.4`.

## Nota de interpretación

La perturbación angular es una aproximación fenomenológica para eliminar trayectorias excesivamente deterministas; no es una dinámica de giro calibrada cuantitativamente contra datos de vuelo de *Drosophila*. Para una validación científica, comparar muchas trayectorias sin estímulo, medir el sesgo medio de yaw (izquierda/derecha), distribución de velocidades angulares y frecuencia de giros, y ajustar amplitud/correlación a datos experimentales. Una sola ejecución aleatoria no demuestra ausencia estadística de sesgo.

## Compilación

El ZIP de entrada no incluye `gradlew` ni el directorio `gradle/wrapper`, y en este entorno no hay Gradle disponible; por eso no se ha podido ejecutar una compilación Android. El código y los recursos se han editado, pero la compilación final debe verificarse en Android Studio o en el workflow de GitHub Actions.
