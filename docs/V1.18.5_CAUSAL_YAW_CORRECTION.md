# FlyBrain v1.18.5 — causal yaw correction

## Scope
This release corrects the body-steering equation only. The frozen MaleCNS v1.0 / FBR-10-OLF2-MOTORROUTE connectome, neuron selection, synapses, transmitter signs, LIF parameters, olfactory field, and food-contact logic are unchanged.

## Root cause addressed
The prior yaw equation added `neckActivity * 0.22f` to the signed left/right leg difference. `neckActivity` is an aggregate nonnegative signal with no lateral sign, so it could contribute a persistent yaw in one direction. The prior implementation also injected an external random yaw term (`exploratoryTurn`), making heading changes partly independent of neural motor output.

## Change
- Yaw now derives from `(rightLeg - leftLeg) * 1.55f`.
- The unsigned aggregate neck activity is no longer interpreted as a left/right steering command.
- Removed the random locomotion yaw generator and its state.
- Retained the slow resting-offset estimate, applied only while physically quiescent.
- Bumped Android version to 1.18.5 / versionCode 138.

## Validation boundary
Static regression tests verify that the unsigned neck term and random yaw path are absent and that the motor-side differential remains the steering input. This is not proof that the biological connectome has balanced left/right motor output. If a persistent neural side difference remains, it must be localized through the side-resolved ORN → DN → leg-MN telemetry rather than cancelled by a hand-authored balancing force. An Android build and new controlled video are still required.
