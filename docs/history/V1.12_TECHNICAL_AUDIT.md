# FlyBrain V1.12 — technical audit

## Evidence used

- User video `1000303404.mp4`: ~135.6 s, 61.6 FPS source, showing continuous locomotion, 0 detected pauses, homeostatic display rising only from 0% to ~6%, food interactions, then danger/escape with arousal rising to ~34%.
- MaleCNS v1.0 is the current project source: the complete male Drosophila CNS connectome produced by HHMI Janelia, Google Research and collaborators.
- Published Drosophila computational LIF model (Shiu et al., 2024) uses signed connectome connectivity and inferred neurotransmitter identity.
- Published halting work identifies Foxglove (FG), Bluebell (BB), and Brake (BRK) as distinct halting populations and distinguishes walk-OFF and brake mechanisms.
- Published 2025 homeostasis work describes minute-scale exponential homeostatic dynamics and short spontaneous rest/sleep bouts.

## Problems identified in V1.11

1. Role 3 descending metadata mixed backward-walking neurons (MDN/DNp09) with generic "halting".
2. A `haltEdgeGain` artificially amplified all role-3 DN→motor edges, which was not a faithful implementation of the identified halting mechanisms.
3. The locomotor state was partly sustained by always-on synthetic central/tonic currents.
4. Pauses were only detected after the body became still, but there was no connectome-grounded protection of the experimentally identified halt populations and their downstream routes.
5. Rest entry/wake behavior had been represented by an external stochastic controller in earlier versions.
6. The homeostat accumulated too slowly in the displayed scale and was previously coupled too directly to behavioral state.
7. The LIF time constants were farther from the published Shiu model than necessary for a mobile approximation.

## V1.12 changes

- Removes the external random REST transition and random pause controller.
- Removes synthetic always-on locomotor/tonic currents.
- Keeps only a small intrinsic background fluctuation for unresolved spontaneous neural activity.
- Separates backward-walking DN role from halting metadata.
- Adds `haltRole`: FG=1, BB=2, BRK=3, derived from published annotation text.
- Forces all identified halt neurons into the 16,669-node reduction.
- Adds a measured halt-route selection score so relevant real intermediate cells are preferentially retained.
- Stores halt role in new FBC103 node records.
- Does not create synthetic edges.
- Does not apply an artificial halt gain to existing edges.
- Detects PAUSA from actual body inactivity at >=0.25 s and STOP at >=1 s.
- Labels continuous inactivity >=5 min as SUEÑO for experimental readout; this is not a neural command.
- Makes sleep pressure a diagnostic/homeostatic state driven by measured wake/rest behavior with minute-scale exponential dynamics.
- Keeps arousal separate; threat does not erase homeostatic pressure.
- Changes the synaptic trace to ~5 ms and refractory period to ~2.2 ms, closer to the published LIF model.
- Changes the membrane leak timescale to ~20 ms in the normalized mobile implementation.
- Keeps the 16,669-neuron target and published signed edges.

## Important limitation

V1.12 still uses a simplified LIF model and a simplified body interface. It is not a validated whole-fly upload. The 10% reduction can omit biologically important neurons and pathways despite route-aware selection. The body remains a low-dimensional readout of measured VNC motor activity.

## Intended test

Run the APK for 10 minutes without touching anything. Record:
- first PAUSA;
- first STOP;
- pause count;
- last pause duration;
- sleep pressure;
- Walk-OFF and BRK evidence;
- whether locomotion naturally stops and restarts.

The critical success criterion is not reaching a numerical pressure threshold. It is whether actual motor output now produces intermittent, irregular pauses without an external pause timer.


## Build correction: MaleCNS halt-type aliases

The V1.12 builder initially classified halt cells only when the Sapkal names (FG/BB/BRK) appeared literally in the downloaded annotation text. MaleCNS v1.0 exposes these cells under its current type names: FG/Foxglove maps to CB0890 / GNG458, BB/Bluebell maps to DNg60, and BRK/Brake maps to AN19A018. The reducer now recognizes these exact MaleCNS aliases, while still only protecting/annotating the real cells and never inventing edges.
