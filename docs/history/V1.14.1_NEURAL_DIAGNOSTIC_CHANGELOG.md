# FlyBrain V1.14.1 — Neural Diagnostic Instrumentation

## Purpose
V1.14.1 preserves the exact frozen FBR-10 MaleCNS v1.0 connectome from V1.14 and changes only presentation/diagnostic instrumentation.

## Frozen connectome — unchanged
- 16,669 selected neurons
- 2,064,951 published directed connections
- 16,783,932 retained contacts

## New diagnostic panel in the white simulation area
The panel is read-only and shows: 
- active DN count / 1,314
- active motor-neuron count / 708
- top 3 currently active DNs by presentation activity, with real MaleCNS bodyId and DN role
- top 3 currently active motor neurons by presentation activity, with real MaleCNS bodyId and motor role
- current population spike rates S/C/DN/M

The diagnostics do not feed back into LIF state, connectome, body mechanics, or behaviour.

## Brain visualization
The representative retained-neuron map now uses three presentation dimensions for recent activity:
1. node radius
2. node brightness/alpha
3. multi-layer halo/glow

Real retained edges also vary in brightness and width according to recent activity. Inactive topology remains visible but subdued. No synthetic edge is introduced.

## Scientific boundary
This version is an instrumentation build. It does not claim that a behaviour is emergent merely because a diagnostic label changes. The purpose is to expose the actual DN/motor activity so the next tests can compare basal, light, danger and food conditions at the individual-neuron level.
