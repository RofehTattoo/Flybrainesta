# FlyBrain V1.15.7-UI — interface redesign

Visual/interface-only revision based on **V1.15.6 FOOD-TUNE-C**.

## What changed
- Removed the two large white cards above the neural visualization.
- Removed the separate diagnostic-card layout from the active UI.
- Enlarged the dark neural-observatory area to use the recovered vertical space.
- Consolidated selected final-use information into a compact integrated dashboard.
- Kept the connectome visualization as the main visual focus.

## Data retained in the final UI
- Model identity: MaleCNS v1.0, FBR-10, FBC103, FBD104, VNCSEM102.
- Neuron / structural-edge / dynamic-edge census and FPS.
- Live stimulus and behavior readout.
- Neural pipeline: S / C / DN / M rates, DN and MN active counts, total spikes/s, OLF and VIS rates.
- Motor output: left/right LEG drive, asymmetry, total drive, absolute drive, peak drive, WING/NECK/ABD drive.
- Body kinematics: speed, acceleration, path length, X/Y, heading, displacement, pause telemetry.
- Top active DN and MN (bodyID, role, Hz).
- WALL distance/signal and MECH rate.

## Scientific invariants
- No changes to FBC103, FBD104, FBR-10 connectivity or VNC semantics.
- No changes to neural dynamics, body mechanics, stimulus encoding or behavioral rules.
- No diagnostic value feeds back into the simulation.
- Base model parameters remain those of V1.15.6 FOOD-TUNE-C: `FOOD_OLF_GAIN = 6.00`, odor `sigma = 1.10`.
