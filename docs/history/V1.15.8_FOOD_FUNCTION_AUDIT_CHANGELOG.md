# FlyBrain V1.15.8 — FOOD FUNCTION AUDIT

## Scope
Runtime-only audit/fix of the olfactory input interface. FBC103, FBD104, FBR-10 node/edge set, VNC semantics and body mechanics remain frozen.

## Fix implemented
`encodeOdor()` previously clamped left and right channels independently to 3.0. At high gain this could make both channels saturate to the same value and erase the directional contrast. V1.15.8 applies one common scale factor to the complete odor pattern, preserving relative L/C/R/front/rear ratios while keeping the pattern bounded.

## Diagnostics added
The UI now exposes the encoded OLF L/C/R channels, `foodDirectionalBias`, and the current projection mode. These values are read-only and never feed back into neural dynamics or body mechanics.

## Frozen parameters
- FOOD_OLF_GAIN = 6.00
- odor sigma = 1.10
- FBC103 SHA-256 = bfadc30fd113c25f9711cce6ef8f6b80e9c139fe6d229965a4adabb94d8b4e60

## Known limitation intentionally exposed
The 12-channel odor pattern is still distributed to the 121 retained OLF neurons by the existing index-cyclic projection. This build does not invent an anatomical receptor-side mapping. The next audit must derive an official-annotation-backed OLF mapping, if the source data support one. If the frozen FBR-10 lacks sufficient olfactory steering coverage, any structural change must receive a new reduction/audit ID rather than silently changing FBC103.
