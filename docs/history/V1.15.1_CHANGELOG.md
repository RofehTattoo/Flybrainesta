# FlyBrain V1.15.1 — Changelog

## VNC → Body Mechanics surgical correction

V1.15.1 corrects the main VNC/body bottlenecks identified by the V1.15.0 video experiments without changing FBR-10 structure or FBD104 signed dynamics.

- Corrected motor-role normalization: LEG/WING/JUMP are now divided by fixed retained role populations, not by the number of currently firing neurons.
- Corrected left/right LEG normalization using the frozen anatomical side census.
- Removed stimulus-identity gating from `driveBody()` turning normalization; body turning is derived from measured motor/body state only.
- Removed the artificial `stableLocomotion` requirement from food intake; contact + gustatory activity now suffice.
- Made locomotion/rest memory derive from measured physical movement.
- Added read-only VNC role telemetry and a CI validator for the frozen 708-neuron motor mapping.
- Bumped app version to 1.15.1 / versionCode 120.

No synthetic neurons, synthetic edges, stimulus-to-body command, or modification of the frozen FBC103 structural layer was introduced.
