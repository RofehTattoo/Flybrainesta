# FlyBrain V1.14.2 — Neural Observatory

## Purpose
Improve observability for controlled experiments without changing the frozen FBR-10 neural substrate.

## Frozen substrate
- MaleCNS v1.0 / FBR-10
- 16,669 selected neurons
- 2,064,951 retained directed edges
- 16,783,932 retained contacts
- FBC103 binary
- Binary SHA-256: `bfadc30fd113c25f9711cce6ef8f6b80e9c139fe6d229965a4adabb94d8b4e60`

## V1.14.2 presentation-only changes
- Larger read-only diagnostic card inside the white simulation area.
- Two columns: DN and motor populations.
- Five top individual DNs and five top individual motor neurons.
- Real MaleCNS body IDs and existing role labels.
- Activity bars for each individual readout.
- Population summary: spikes/s, sensory, central, DN and motor rates.
- Rolling 5-second Neural/DN/Motor activity history.
- Existing live brain-map visualization retained: node size, brightness, halo, edge width and edge intensity respond to measured activity.
- History arrays are presentation-only and never feed back into the LIF state or body mechanics.

## Explicit non-changes
No neuron selection, edge, weight, neurotransmitter sign, LIF parameter, sensory current, motor equation, or behavioral rule was intentionally changed by this version.
