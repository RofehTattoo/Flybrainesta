# FlyBrain V1.19.9 — yaw stabilization and system-bar layout

## Changes
- Neural yaw now requires a meaningful amount of measured stance propulsion; tiny left/right residuals no longer normalize into a full turn command.
- Neural yaw is attenuated during walk-off/feeding pause. The physical wall-contact escape reflex remains independent.
- The app applies system-bar and display-cutout insets to the root content and consumes them, keeping the custom-drawn neural panel above Android navigation controls.
- The neural-panel subtitle is shortened so it no longer collides with the live connection status.
- Release metadata and CI connectome regeneration are synchronized to version 1.19.9 / versionCode 150.

## Validation scope
Static regression tests and archive integrity are checked locally. This source archive does not include a Gradle wrapper; an Android APK build must be confirmed by CI.
