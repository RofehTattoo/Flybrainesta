# FlyBrain V1.19.14 — visual response fix

The FBR-10 route scorer previously used broad channel-0 visual input when preserving `route_turn`/`route_escape`. The Android runtime, however, injects external current only into anatomically identified R1-6/R7/R8 photoreceptors. V1.19.14 adds an endpoint-faithful `is_primary_visual_receptor` route score, so reduction selection protects the same visual input endpoints that the app actually stimulates. The runtime encoder also separates sustained light from danger looming at the photoreceptor input, without writing body pose/heading or bypassing the connectome.
