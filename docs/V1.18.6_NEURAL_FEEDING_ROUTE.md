# FlyBrain V1.18.6 — neural feeding route audit

## Root cause found in V1.18.5
The retained feeding motor neurons in MaleCNS are `cb_motor` neurons in the brain, not members of the legacy VNC locomotor block. The runtime therefore could simulate their spikes without ever consuming them as a motor/readout channel. At the same time, the tarsal contact encoder injected the same contact signal into the entire retained GUST block instead of restricting contact to the official `leg bristle` subclass.

## Correction
1. `build_feeding_motor_semantics.py` generates `FEEDSEM103` from the official MaleCNS v1.0 annotations and maps the retained types MN9, MN4a, MN6, MN8, MN11D/MN11V and CEM to read-only functional tags.
2. `MainActivity` counts spikes from those retained `cb_motor` neurons over every 0.5 ms substep.
3. The visual proboscis extension is driven by measured MN9 (rostrum) activity. It is not triggered by a food/contact flag.
4. Ingestion is acknowledged only from real retained ingestion-related motor spikes (MN11D/MN11V/CEM) in a concurrent food/taste context. Satiety is updated only on such an ingestion event.
5. Tarsal contact is bilateral and is mapped only to retained gustatory neurons whose official `subclass` is `leg bristle`; labellar/pharyngeal/other gustatory neurons remain GUST but are not substituted for tarsal receptors.
6. A 0.50 s read-only temporal association window links measured taste/proboscis/ingestion spikes into one episode. It compensates for the fact that the multilayer circuit need not peak in the same 20 ms public frame; it does not inject spikes, stop locomotion, move the fly, or synthesize an ingestion event.
7. The existing VNC locomotor body mechanics and V1.18.5 CAUSAL TURN equation are unchanged. No food→speed, food→heading, synthetic halt, synthetic edge or synthetic feeding motor command is added.

## Scientific boundary
The sequence `CONTACTO → GUSTACIÓN → HALT → PROBÓSCIDE → INGESTIÓN` is useful as an experimental audit sequence, but the biological circuit is not a rigid if/then controller. Gustatory feeding initiation is implemented through multilayered SEZ circuits that converge on proboscis motor neurons, and feeding can be modulated by odor and hunger state. The simulator therefore records HALT as neural/physical evidence rather than forcing it as a prerequisite for proboscis output.

## Verification target for the next APK run
At food contact the telemetry should now allow us to distinguish:
- tarsal GUST spikes: sensory taste actually occurred;
- HALT evidence + physical speed: locomotor arrest actually occurred;
- MN9/MN4a/MN6/MN8 spikes: proboscis motor output actually occurred;
- MN11D/MN11V/CEM spikes: ingestion motor output actually occurred;
- `ING` counter: only a true measured ingestion episode increments it.

The key success criterion is not that a canned animation appears, but that the retained MaleCNS network produces measurable feeding-motor output from the existing synapses.
