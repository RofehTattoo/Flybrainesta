It stopped in `tools/test_food_response_chain.py` because a static test still
expected the pre-feeding-dwell actuator call:

`legActuator.step(legGroupActivation, walkOffActivationState, dt)`

through `effectiveWalkOffActivation`. Updated the stale food-response and causal
yaw static assertions to validate the new call and preserve checks that the
feeding pause is present in the body loop.

No production Kotlin, connectome, or locomotor parameters were changed in this
CI-only correction.
