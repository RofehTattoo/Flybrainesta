# V1.19.12 build fix

The first V1.19.12 archive failed at `:app:compileDebugKotlin` for two Kotlin source errors in `MainActivity.kt`:

- `StartupView` declared `Entry` as a nested `data class` inside an `inner class`; moved the value type to the enclosing `MainActivity` scope as `StartupEntry`.
- `StartupView` reads three load-state values from `FlyView`; removed their `private` visibility while retaining `@Volatile` so the startup view can observe the background loader's state.

No connectome, FBR-10, locomotion, arena-bound, or wall-reflex behavior was changed in this build-only correction.

The startup/arena/wall regression checks, compact UI regression checks, release provenance check, and generated-connectome validation pass. A full Android Gradle build was not run in this environment because Gradle/Gradle wrapper and Android SDK are not available here; GitHub Actions should be rerun to confirm compilation.
