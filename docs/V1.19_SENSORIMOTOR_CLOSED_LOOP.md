# FlyBrain V1.19.0 — SENSORIMOTOR CLOSED LOOP

## Scope

V1.19.0 addresses the main behavioural failure observed in V1.18.7: retained leg-MN activity could coexist with weak or absent physical displacement, while the visual body motion was still too close to a point-mass decoder. The correction keeps the FBR-10/FBC103/FBD105 connectome immutable and changes only the runtime actuator/feedback layer.

## Closed loop

`retained LEG MN groups → six-leg mechanical state → body velocity/yaw → mechanical/proprioceptive feedback → retained MECH receptors → FBR-10`

The feedback is one public 20 ms frame delayed because `sense()` runs before `driveBody()`; the following neural frame therefore sees the mechanical state generated by the preceding frame. No external food/light/danger state enters the actuator.

## Six leg groups

The existing official VNC semantics remain the sole source of LF/LM/LH/RF/RM/RH membership. The actuator keeps independent phase, stance, swing, contact, load, stride, lift and extension state for all six groups. A fixed modified-tripod phase relation is used only as a mechanical kinematic constraint; phase does not advance when measured leg output is absent.

## Body mechanics

Body translation is no longer updated as `drive × displayFPS`. Forward motion comes from supported leg load and a damped inertial state. Lateral motion and yaw arise from the persistent left/right LEG-MN motor imbalance; alternating tripod support is used only for mechanical stance/contact state and must not create a false steering oscillation. Wall interaction projects the body velocity against the boundary instead of reflecting the heading. Wings are not a ground-translation input.

## Proprioceptive return

The retained MECH population receives a side-resolved encoding of the previous frame's leg contact/load/swing state and body dynamics. Wall proximity remains a smaller environmental mechanosensory component. The runtime does not create neurons or edges.

## Food pathway

The feeding route remains separate from the mechanical actuator:

`odor → neural navigation → tarsal contact → gustatory receptors → retained network → feeding-related motor readouts`

No `food → speed`, `food → heading`, `food → eat` or renderer-only feeding shortcut is introduced.

## Frozen structures

- FBR-10 neuron set: unchanged.
- FBC103 connectivity: unchanged.
- FBD105 dynamics: unchanged.
- Olfactory reduction and tarsal gustatory purity: unchanged.
- V1.18.5 causal turn correction: no random steering is reintroduced.

## Required validation

The Android build must be run through CI and then tested for: six-leg phase coordination, start/stop continuity, body response to bilateral motor asymmetry, mechanical feedback activity, wall contact, and the complete contact/gustation/feeding sequence.
