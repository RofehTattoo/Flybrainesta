# V1.19.15 — bilateral visual encoding and looming persistence

The V1.19.14 runtime was receiving a single identical Poisson rate across the
whole retained VIS receptor set. That could produce strong visual firing while
removing the left/right information needed for steering or escape.

This release changes only the runtime sensory encoder:

- Retained R1-6/R7/R8 photoreceptors now consume their official `sideCode` from
  `sensory_input_map.tsv`.
- Light and danger are projected into the fly body frame and produce asymmetric
  left/right receptor rates according to stimulus azimuth.
- Danger keeps a sustained visual component and a short onset/looming memory, so
  a stationary visible threat does not disappear after one frame and a sudden
  approach is not limited to a single 20 ms pulse.
- `driveBody()` remains isolated from stimulus/action variables; movement still
  comes exclusively from measured VNC motor output through the existing
  `LeggedSensorimotorActuator`.

FBR-10/FBC103 is not regenerated or structurally changed by this fix.
