# V1.19.0 CI fix — olfactory input-map test

The CI failure was a stale static assertion in `tools/test_olfactory_input_map.py`.
It expected the pre-V1.19 direct wall-only mapping:

`setMappedSensoryRate(mechanosensoryReceptorIndices, wallSignal * 80f)`

V1.19 intentionally replaced that line with a closed-loop MECH input combining wall proximity and the actuator's one-frame-delayed proprioceptive state:

`wallSignal * 26f + local * 92f + mechGlobal * 18f`

The test now asserts the current pathway and rejects the obsolete expression. No runtime code, connectome data, neural parameters, motor behavior, or app version was changed.
