# FlyBrain V1.19.7 — feeding stop / taste dwell

The fly already detects food, activates gustation and extends the proboscis, but
fast locomotion can carry it across the source before walk-OFF becomes effective.

This release adds a finite feeding dwell generated from measured neural feeding
events: gustatory/taste activity creates a short hold; proboscis motor activity
creates a stronger/longer hold; ingestion motor activity creates the strongest/
longest hold.

The dwell is merged with the same locomotor walk-off path used by the six-leg
actuator. The leg actuator remains unaware of food position and `foodOn`.

FBR-10 neuron/edge data are unchanged.
