# FlyBrain V1.20.0 — Neuromuscular Embodiment

## Intent

V1.20 replaces the V1.19.1 phase-driven leg actuator with a phase-free, per-leg mechanical interface. The immutable FBR-10 connectome and FBD105 neural dynamics remain unchanged.

## Removed

- The `TRIPOD_OFFSETS` phase table.
- The `STANCE_DUTY` clock and synthetic stance/swing cycle.
- Per-leg baseline adaptation and baseline-subtracted burst detection in `driveBody()`.
- A generated gait frequency derived from motor activation.

## New motor boundary

Each neural frame, the six anatomically labelled leg-group population firing rates (LF, LM, LH, RF, RM, RH) are passed to the actuator directly. A short motor activation time constant and a persistent joint state represent actuator dynamics. Foot displacement follows joint state; only foot displacement while in the simplified ground-contact state contributes to body force. Bilateral force asymmetry contributes to yaw. The mechanical state returns contact/load/joint-state/joint-velocity summaries as proprioceptive signals.

The body-wall constraint removes only velocity directed through the wall, preserves tangential motion, and produces a contact pressure signal even when the body has already slowed to zero. It does not reflect heading or inject a turn command.

## Scientific limits (must not be overclaimed)

- The current semantic map identifies each retained leg MN's leg/side group, but does not yet provide a validated muscle-specific motor-unit map for every MN. The actuator therefore does **not** claim muscle-level fidelity.
- The current input is a per-leg population firing rate per neural frame. It preserves frame-to-frame temporal variation but not each neuron's identity/spike timestamp as a separate muscle command.
- The ground plane/contact model is simplified. It is not a full rigid-body/contact solver and does not model each tarsus colliding with arena walls.
- No spontaneous pauses are injected. Pause bouts can only emerge if neural motor output falls sufficiently; if the reduced network lacks the needed temporal dynamics, this version will expose that limitation rather than fabricate pauses.
- Feeding, gustation, olfaction and the connectome are not retuned in this release. Ingestion remains contingent on the existing neural/event criteria.
- A constant motor firing rate causes a finite joint transition, not a perpetual synthetic gait. Sustained walking requires time-varying motor output from the neural simulation. This is deliberate and diagnostically useful, but may reduce apparent locomotion if the current reduced network does not generate such patterns.
