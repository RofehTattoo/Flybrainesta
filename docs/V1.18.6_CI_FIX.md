# V1.18.6 CI fix — gustatory topology audit invocation

The GitHub Actions step `Audit retained gustatory-to-feeding topology` used a
single-line YAML `run:` scalar with shell continuation backslashes. YAML folded
the physical newlines, so the Python audit was invoked without its required
`--annotations` and `--fbc103` arguments. The workflow failed at argument
parsing (exit code 2), before the topology audit itself ran.

The step now uses a literal block scalar (`run: |`), preserving shell newlines
and passing both required arguments on separate continued lines.

This is a CI/workflow-only correction. It does not change Kotlin runtime logic,
FBR-10/FBC103 structure, neuron selection, edges, LIF parameters, feeding
semantics, or the CAUSAL TURN correction. The next GitHub Actions run must
execute the topology audit; its result will then tell us whether the retained
graph passes the actual gustatory-to-feeding reachability assertions.
