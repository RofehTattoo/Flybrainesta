# FlyBrain V1.19.16 — FBR-10 visual reconstruction

The V1.19.15 runtime-only visual fix did not address the underlying reduction bottleneck.
The new release reopens the FBR-10 selection specifically for the visual slice while keeping
the global target at exactly 16,669 neurons and retaining only published MaleCNS edges.

## Primary photoreceptors
The selector counts the pinned MaleCNS v1.0 primary R1-6/R7/R8 photoreceptors from the
source annotation and reserves exactly 10% of them. The quota is stratified by receptor
family (R1-6/R7/R8) and official side metadata so the reduced retina remains bilateral.

## Visual relay circuit
The remaining visual-channel budget is reserved for measured optic-lobe relay neurons.
Route preservation uses both direct photoreceptor -> candidate -> DN paths and measured
photoreceptor -> A -> B -> DN paths for turning and escape DNs. No edge is synthesized.

## Runtime contract
The sensory map now fails closed if the retained visual receptor count is not exactly the
10% source quota. This prevents a future reducer change from silently rebuilding the previous
12-receptor bottleneck.

## Version
FlyBrain 1.19.16 / versionCode 157.

### Co-selection closure

Primary photoreceptors are selected using measured downstream visual route support
in addition to degree, with the quota balanced by R1-6/R7/R8 family and official
side. The optic-lobe relay quota is then re-scored against the photoreceptors
actually retained. Before publishing FBC103, the builder performs an induced-subgraph
audit requiring at least one retained photoreceptor→relay→turn-DN bridge and one
retained photoreceptor→relay→escape-DN bridge. All of these checks use only
published MaleCNS edges; no connection is synthesized.
