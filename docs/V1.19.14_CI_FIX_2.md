# V1.19.14 CI fix 2 — ORN map index guard

The uploaded GitHub Actions log failed during runtime-map generation, after the
connectome and structural checks passed. The failing guard assumed no officially
annotated ORN could have an FBC index in the historical 618–738 interval.

That assumption is invalid: FBC index ranges are not modality labels. The runtime
map remains selected strictly by official MaleCNS annotations and retained bodyIds.
The index overlap is now recorded as a diagnostic instead of aborting generation.
No connectome nodes, edges, ORN selection criteria, or runtime stimulus behavior
were changed.

The log's structural tests and connectome validation passed; the failure occurred
when `tools/build_olfactory_input_map.py` raised:
`historical 618..738 visual OLF block overlaps real ORN map`.
