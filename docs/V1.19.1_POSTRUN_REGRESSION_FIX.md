# FlyBrain V1.19.1 — post-run regression correction

The first compiled V1.19.0 run exposed three runtime defects that were separate from the frozen FBR-10 graph:

1. Pause telemetry was evaluated before the just-computed physical speed, so the displayed pause state could remain at zero even when the body had stopped. V1.19.1 evaluates the measured speed first and then updates the pause state; pauses remain measured events, not injected behavior.
2. Wall mechanosensory input was mixed using screen-top/screen-bottom side assignments. V1.19.1 resolves boundary normals in the fly body frame and maps left/right/front/rear pressure without synthetic steering. The wall actuator removes only the outward velocity component and preserves tangential slip with damping.
3. Food depletion is now visible only while physical food remains. Ingestion still requires measured gustatory context plus retained feeding-motor spikes; no direct contact→eat command exists.

The connectome binary is unchanged. No FBR-10/FBC103 neuron or edge is added or edited.
