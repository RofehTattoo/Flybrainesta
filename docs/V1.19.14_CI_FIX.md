# V1.19.14 CI fix

The visual-response change added `is_primary_visual_receptor()` to the connectome
builder, which correctly checks `superclass == "ol_sensory"` for primary visual
photoreceptors. The existing olfactory route test incorrectly asserted that this
string must not occur anywhere in the builder. Updated the test to require the
visual predicate while independently checking the `cb_sensory` olfactory path.
No runtime code, connectome binary, or model parameters were changed by this CI fix.
