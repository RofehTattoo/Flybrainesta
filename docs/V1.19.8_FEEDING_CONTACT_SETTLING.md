# FlyBrain V1.19.8 — feeding contact settling

## Corrections from V1.19.7

1. **Longer event-renewed dwell:** taste, proboscis and ingestion holds are now 1.20 s, 2.40 s and 3.00 s respectively. They renew only when the corresponding measured neural event occurs.
2. **Physical stop:** the residual gait gate is now squared. As measured neural walk-off approaches 1, the remaining gait drive collapses more strongly, so a pause does not leave the fly creeping forward on a weak residual tripod cycle. The actuator still receives only neural/derived motor state; it has no access to food coordinates or food flags.
3. **Delayed ingestion association:** the pharyngeal-contact context window is extended from 0.35 s to 0.80 s, matching the existing short gustatory/proboscis association window. This only allows real MN11D/MN11V/CEM spikes to be associated with recent contact; it does not create spikes, force ingestion, or reduce food amount by itself.
4. **Preserved boundary:** ingestion, satiety and food depletion still require measured ingestion-related motor-neuron events. FBR-10/connectome data and sensory maps are unchanged.

## Verification target on device

At the banana, check that measured gustatory/proboscis activity now produces a decisive physical stop rather than a slow crawl. Then check whether the `ING` counter increments and food percentage falls. If the fly stops but `ING` remains 0, the remaining issue is upstream neural recruitment of retained MN11D/MN11V/CEM—not a reason to synthesize ingestion in the UI or actuator.
