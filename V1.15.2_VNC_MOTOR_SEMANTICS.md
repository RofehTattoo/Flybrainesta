# FlyBrain V1.15.2 — VNC Motor Semantics

## Scope

V1.15.2 changes only the semantic translation between retained VNC motor neurons and the body layer.

**Frozen:**
- FBR-10 node set: 16,669
- FBC103 structural binary
- FBC103 edges and structural weights
- FBD104 signed dynamics layer

The frozen FBC103 motor-role byte is retained for provenance/audit comparison. Runtime body semantics are loaded from a separate `vnc_motor_semantics.tsv` asset generated from the exact official MaleCNS v1.0 annotation Feather.

## Anatomical classes

The official annotation `class` is the source of truth:

- `leg` → LEG
- `wing` → WING
- `abdominal` → ABDOMEN
- `neck` → NECK
- `haltere` → HALTERE
- `other` → OTHER

There is no anatomical JUMP class.

`TTMn` remains anatomically WING and receives the engineering-only `functionalTag=JUMP`.

## Census gate

The generated map must contain exactly 708 VNC motor neurons:

- LEG: 381
- ABDOMEN: 214
- WING: 67
- NECK: 24
- HALTERE: 16
- OTHER: 6
- side: 355 L / 353 R

## Body coupling

Only documented anatomical motor populations are coupled to the existing body mechanics. Unknown/OTHER motors remain visible and counted; they are never silently removed from neural activity. No stimulus identity is injected into body mechanics.

For V1.15.2, TTMn's jump tag is a functional annotation layered on top of WING; it does not alter the anatomical census.
