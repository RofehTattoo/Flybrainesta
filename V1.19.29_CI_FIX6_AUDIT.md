# V1.19.29 CI FIX6

## Root cause
The canonical FBR-10 build itself passes. CI fails in the legacy visual-FBR10
regression contract because `tools/test_v11916_visual_fbr10_rebuild.py` still
expects APP_VERSION_CODE 169, while V1.19.29 correctly uses 170.

A scan found the same stale release contract in several older regression tests.
They were all still validating the current app metadata against V1.19.28/169.

## Fix
Synchronize current-version assertions in `tools/test_*.py` to:
- APP_VERSION = 1.19.29
- APP_VERSION_CODE = 170
- versionName = 1.19.29
- versionCode = 170

No FBR-10 topology, sensory map, locomotion mechanics, wall logic, or neural
control was changed.
