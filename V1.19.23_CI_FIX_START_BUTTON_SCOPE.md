# V1.19.23 — CI FIX: START BUTTON SCOPE

## Root cause
GitHub Actions reached `:app:compileDebugKotlin` and failed because `StartupView.onDraw()` referenced `startButton`, but `startButton` had been declared as a local variable inside `onCreate()`. The Kotlin compiler therefore reported `Unresolved reference 'startButton'` at lines 341, 342, 347 and 348.

## Fix
`startButton` is now an Activity-level `lateinit var`, initialized before the startup overlay is attached. The click handler and `StartupView` both reference the same button instance. No simulation logic, connectome data, anatomy mapping, locomotion, or visual sizing parameters were changed.

## Validation
- Static UI regression test updated to V1.19.23 / versionCode 164.
- Kotlin source scope checked: one Activity-level declaration, no shadowing local declaration.
- The previous GitHub failure was compile-time only; a fresh GitHub Actions run is still required to confirm the Android build.
