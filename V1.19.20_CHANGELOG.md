# FlyBrain V1.19.20 — changelog

## Release type

**Stabilization + validation.** No expansion of the FBR-10 neuron or edge set.

## Functional changes

1. The physical/mechanical body integration has been isolated in
   `applyMechanicalBodyState(dt)`.
   This method consumes only the measured six-group VNC leg motor state and
   retained walk-OFF activity. It does not accept or inspect food, light, danger
   or action-selection variables.

2. The leg actuator exposes read-only validation telemetry:
   `forwardForceProxy`, `yawForceProxy`, `supportCoverage`,
   `bilateralMechanicalSymmetry`, and `tripodPhaseCoherence`.
   These values do not feed back into neural dynamics.

3. Tripod validation uses static RF→LM→RH and LF→RM→LH group definitions to avoid
   per-frame allocation in the mechanical telemetry path.

4. The active release metadata is synchronized to version 1.19.20 / versionCode 161,
   including the Android manifest label and FBR-10 OLF2 release manifest.

5. The authoritative MaleCNS neurotransmitter SHA-256 in `GeneratedConnectomeMeta.kt`
   and the release manifest is corrected to the pinned source value used by
   `prepare_malecns.py` and `build_fbr10_dynamics.py`.

6. CI runs `tools/test_v120_locomotion_validation.py` before the structural validation
   suite.

## New validation gates

The release tests verify:

- no motor output → no free-running leg oscillator and no body movement;
- symmetric six-leg motor output → no persistent yaw bias over a gait window;
- asymmetric left/right leg output → deterministic yaw with the established sign;
- measured walk-OFF → mechanical locomotor braking;
- motor output removal → leg phase freezes and body speed decays;
- mechanical body integration has no direct environment/action inputs;
- wall contact is resolved from physical wall geometry without heading reflection;
- the olfactory → retained network → DN/VNC → leg route remains the source of motor drive;
- the renderer displays the same motor-driven leg state used by the actuator.

## Biological scope and limits

The release is consistent with documented principles of adult *Drosophila*
walking: six-leg coordination, a modified-tripod gait during forward walking,
and locomotion arising from interaction between neural control, the legs and the
body/environment. The current runtime is still a reduced normalized 2D
neuromechanical model; it is not presented as a full experimental reconstruction
of muscle forces, tendons, body mass/inertia, three-dimensional center-of-mass
kinematics, or flight mechanics.

## Connectome integrity

FBR-10-OLF2-MOTORROUTE remains the release reduction. No synthetic neuron,
synthetic edge, odorant-receptor affinity table, or direct sensory-to-body shortcut
was added in V1.19.20.
