# FlyBrain V1.19.37 — CI contract repair

## Root cause of V1.19.36 CI failure

The uploaded V1.19.36 source already contained the frozen FBR-10 SHA-256 metadata, but
the GitHub Actions run checked out a repository state in which
`GeneratedConnectomeMeta.kt` did not expose the required `BINARY_SHA256` declaration.
`tools/test_v136_neural_turn_yaw.py` therefore stopped the structural validation job
before Android build/runtime validation.

This is a release-contract/repository-state failure, not evidence that the retained
TURN-DN yaw implementation itself failed.

- `GeneratedConnectomeMeta.BINARY_SHA256` is explicitly present and equals:
  `0044ab166af3439f2b86d4e6c5897481a1c3f28a58b6afb2c4f761489b276bbf`
- TURN audit now checks the exact Kotlin declaration (`const val ...`).
- No connectome bytes were changed.
- No yaw/arena behavioral code was changed.
- No food/light/danger shortcuts were introduced.
