# V1.16.0 — FOOD / OLFACTION CLEANUP

Scope: ONLY olfaction, COMIDA sensory encoding, and diagnostic food-following readouts. FBC103/FBD104/body mechanics remain frozen.

## Removed from the food sensory path
- Index-cyclic `((i * 17) % pattern.size)` projection into OLF.
- Per-neuron sinusoidal `micro` modulation for OLF input.
- Artificial 12-channel L/C/R/front/rear odor pattern as the runtime OLF source.
- Independent L/R saturation via a pattern cap.
- `foodDirectionalBias` as a gate on the approach readout.
- Unused `feedingDemand` variable.

## New source-backed path
1. CI downloads the exact pinned MaleCNS v1.0 annotation Feather already used by FBR-10.
2. `build_olfactory_input_map.py` reads the 121 retained OLF bodyIds from FBC103 and joins them to official annotations.
3. Side evidence priority: `somaSide`, then `rootSide`, then an explicit L/R token in `entryNerve`. Contradictions fail closed.
4. If no explicit side is available, the neuron is represented as bilateral/unknown; no side is invented.
5. Runtime samples the environmental odor at two virtual antenna positions and injects the resulting current directly into the corresponding retained OLF neurons according to the official map.
6. No OLF signal writes motor state, turn state, DN state, or body position directly.

## Scientific boundary
The antenna geometry and odor-distance kernel are an environmental sensor-interface model, not a neural behavior rule. The neural response and any resulting food-directed movement must still emerge through the frozen FBR-10 graph and FBD104 dynamics.
